# Wong Zi Yu, Codie — Portfolio

Files:
- `index.html`: Rose Quartz website with animations and **Generate PDF** button.
- `Wong_Zi_Yu_Codie_Portfolio.pdf`: formal monochrome A4 portfolio, with a serif heading and clean sans-serif body text.

Open `index.html` in Chrome or Edge. On the site, click **Generate PDF**, then choose **Save as PDF** in the print dialog. If necessary, disable browser headers and footers.

For GitHub Pages, create a public repository named `YOUR_USERNAME.github.io`, upload `index.html` and PDF to the repository root, and enable **Settings → Pages → Deploy from a branch → main → /(root)**.

No GitHub project links are included on the portfolio itself.
